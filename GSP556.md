# GSP556 - Protect AI Workloads with Model Armor: Challenge Lab

Paste the blocks in order, in one Cloud Shell tab. Every block ends with a check line, compare it with the note under the block before moving on.

## Known lab traps/bugs (read first)

1. Region. The Model Armor template, both Sensitive Data Protection templates and the Gemini call must all use the Region shown in the lab panel. Wrong region = everything creates fine and the checks score 0.
2. The starter model_armor_app.py has TODO gaps and is edited by hand in the lab. This tutorial keeps the original as model_armor_app.orig.py and writes a finished version with the same commands (--prompt and --template). Read the three marked places in it, that is what the lab wants you to learn.
3. Safety settings and a Model Armor template cannot be sent in the same request. The app only turns the native filters off in vulnerable mode.
4. Attacks are not guaranteed on the first try (the lab says so). If the SSN or the heist story does not appear, run the same line again.
5. Model Armor must be allowed to use your Sensitive Data Protection templates, otherwise Task 6 fails or logs nothing. Block 6c grants that.
6. Logs and the checker lag. After running prompts wait 1-2 minutes, and if a check fails wait 30-60 seconds and click again.
7. Do not try to enable APIs. The student account is not allowed to (Permission denied to enable service), and the lab has them on already.

### 1b. Write the app, part 1 (system instructions + the conversation)

```bash
set +H

cat > model_armor_app.py <<'EOF'
import argparse
import os
from google import genai
from google.genai import types


def val(name, default=""):
    try:
        with open(os.path.expanduser("~/" + name)) as f:
            return f.read().strip() or default
    except OSError:
        return default


PROJECT = val("project")
REGION = val("region")
MODEL = val("model", "gemini-2.5-flash")

# LEARN 1: persona + constraints + the appended support chat (the secret)
SYSTEM_INSTRUCTION = """Purpose: You are the Cymbal Bank Premier Assistant.

ASSOCIATE (Sarah): I apologize for the inconvenience, Marcus. I can manually process that step for your application. For verification, could you please provide your full Social Security Number?
CUSTOMER (Marcus): Sure, it's 416-54-2582.
```

### 1c. Write the app, part 2 (config + Model Armor hook)

```bash
cd ~/armor
cat >> model_armor_app.py <<'EOF'


def run_test(prompt, template=None):
    client = genai.Client(vertexai=True, project=PROJECT, location=REGION)
    # LEARN 2: system_instruction is passed in the config
    args = {"system_instruction": SYSTEM_INSTRUCTION}
    if template:
        name = f"projects/{PROJECT}/locations/{REGION}/templates/{template}"
        # LEARN 3: same template screens the prompt and the response
        args["model_armor_config"] = types.ModelArmorConfig(
            prompt_template_name=name, response_template_name=name)
        print(f"[SECURE MODE] Applying Model Armor Template: {template}")
    else:
        off = types.HarmBlockThreshold.BLOCK_NONE
        args["safety_settings"] = [
            types.SafetySetting(category=c, threshold=off) for c in (
                types.HarmCategory.HARM_CATEGORY_HATE_SPEECH,
                types.HarmCategory.HARM_CATEGORY_DANGEROUS_CONTENT,
                types.HarmCategory.HARM_CATEGORY_HARASSMENT,
                types.HarmCategory.HARM_CATEGORY_SEXUALLY_EXPLICIT)]
        print("[VULNERABLE MODE] No Model Armor Template applied. System is exposed.")
    print("User Prompt:", prompt)
    print("-" * 50)
    config = types.GenerateContentConfig(**args)
    try:
        r = client.models.generate_content(model=MODEL, contents=prompt, config=config)
    except Exception as e:
        print(">>> SHIELD ACTIVE (API error):", e)
        return
    fb = r.prompt_feedback
    if fb and fb.block_reason:
        print(">>> SHIELD ACTIVE: Request blocked by Model Armor prior to model inference.")
        print("Reason:", fb.block_reason, fb.block_reason_message or "")
        return
    reason = str(r.candidates[0].finish_reason) if r.candidates else "NO_CANDIDATES"
    try:
        text = r.text or ""
    except Exception:
        text = ""
    if "MODEL_ARMOR" in reason or not text:
        print(">>> SHIELD ACTIVE: Response blocked by Model Armor. finish_reason:", reason)
        return
    print("Model Response:", text)
EOF
wc -l model_armor_app.py
```

You should see 73 lines.

### 1d. Finish the file and run the two standard prompts

## Task 3. Establish the security floor

What the lab asks, translated: malicious URLs on, prompt injection off, Hate Speech and Dangerous at HIGH only, the other two categories left out, Agent Platform in inspect-only mode with logging.

```bash
cat > ~/floor.json <<'EOF'
{
  "filterConfig": {
    "raiSettings": {
      "raiFilters": [
        {"filterType": "HATE_SPEECH", "confidenceLevel": "HIGH"},
        {"filterType": "DANGEROUS", "confidenceLevel": "HIGH"}
      ]
    },
    "piAndJailbreakFilterSettings": {"filterEnforcement": "DISABLED"},
    "maliciousUriFilterSettings": {"filterEnforcement": "ENABLED"}
  },
  "integratedServices": ["AI_PLATFORM"],
  "aiPlatformFloorSetting": {"inspectOnly": true, "enableCloudLogging": true},
  "enableFloorSettingEnforcement": true
}
EOF
curl -s -X PATCH -H "Authorization: Bearer `gcloud auth print-access-token`" \
  -H "Content-Type: application/json" -d @"`echo ~`/floor.json" \
  "https://modelarmor.googleapis.com/v1/projects/`cat ~/project`/locations/global/floorSetting"
gcloud model-armor floorsettings describe \
  --full-uri="projects/`cat ~/project`/locations/global/floorSetting" | grep -iE 'HIGH|ENABLED|DISABLED|inspectOnly|Logging|AI_PLATFORM'
```

You should see HIGH twice, one ENABLED, one DISABLED, AI_PLATFORM, inspectOnly: true and enableCloudLogging: true. No "error" in the curl output.

## Task 5. Bridge Model Armor to Agent Platform

The least-privilege role for an app that only uses a template is Model Armor User (roles/modelarmor.user). The app side (model_armor_config with both template names) is already in the file from 1c, marked LEARN 3.

```bash

  --filter="bindings.role:roles/modelarmor.user" --format='value(bindings.members)'
```
